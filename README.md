# 🚀 TaskHive – Team Task Manager

**Live App:** https://project-pilot-41.lovable.app

TaskHive is a modern team task management platform designed to help teams plan projects, assign tasks, and track productivity in one unified workspace. It streamlines collaboration, improves accountability, and ensures projects stay on track.

---

## 📌 Features

* ✅ **Project Planning**
  Organize work into structured projects with clear goals and timelines.

* 📝 **Task Management**
  Create, assign, and prioritize tasks with ease.

* 👥 **Team Collaboration**
  Assign tasks to team members and track ownership.

* 📊 **Productivity Tracking**
  Monitor progress and performance across projects.

* ⏱️ **Real-Time Updates**
  Stay in sync with live task status updates.

* 🎯 **Professional Workspace**
  Clean and intuitive UI for efficient workflow management.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/taskhive.git
cd taskhive
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

### 4. Open in Browser

```
http://localhost:3000
```
